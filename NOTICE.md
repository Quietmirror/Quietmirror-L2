This is an original ergonomic fit prototype. V0.3 adds separate experimental side caps; they are not a functional switch mechanism. It is not an assembled mouse, an endorsement by the referenced authors, or a verified replacement shell for a named donor.

G-Wolves Fenrir Pro / Asym official product photos were inspected for V0.4. They are linked, not redistributed or relicensed. V0.4 upper geometry is original; its frozen bottom reuses this project's own V0.3 STEP. No Fenrir CAD or mesh was obtained or copied. See `references/FENRIR_REFERENCE.md`.

V0.5 changes only the rear perforation layout of this project's original V0.4 shell, using mirrored, contour-clipped Voronoi cells with rounded corners. It retains the original right-hand side interface and frozen V0.3 bottom. No additional third-party code, geometry or commercial image has been incorporated.
