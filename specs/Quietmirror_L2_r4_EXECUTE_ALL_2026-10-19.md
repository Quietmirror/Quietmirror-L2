## 4. G6 装配顺序和装入路线（作者已验证）

**验证方法：**
- V2 BODY（= 发布的 BODY 加 D1、D4、D5、D6）三角化后，用竖直射线奇偶法体素化，体素 0.25 mm；
- 再整体膨胀 0.25 mm，相当于要求间隙 ≥ 0.25；
- 零件用 0.25 mm 间距的内部点云表示；
- 平移每 0.25 mm 检查一个姿态，绕 Z 轴转动每 5° 检查一个姿态；
- 已装好的零件计为后续零件的障碍物。微动端子穿过挡板槽口属于设计配合，不计碰撞。

**结果：** 共 759 个姿态，**全部无碰撞**。

### 4.1 顺序

1. 两颗 D2F-01F 先焊好导线；
2. **SR 微动** → 3. **SF 微动** → 4. **SR 挡板** → 5. **SF 挡板**，四件都从 BODY 底部开口进入；
6. 从底部拧 2 颗 M2 × 5，固定两块挡板；
7. 键帽从外侧沿 −X 直线推入（D7，§4.4）。推杆压盘上的 PET 调整膜在推入前贴好；
8. 钢销从顶面窗口压入；
9. 其余按 R3.2 原顺序装配（滚轮载架、主键微动、主键、电子件）。

> 顺序不能换：SF 微动的路线会经过 SR 挡板的位置，所以 SF 微动必须先于 SR 挡板装入。

### 4.2 路线

表中坐标是零件**相对最终位置的偏移**（mm）。yaw 是绕零件中心竖直轴的转角（°）。路线按“从壳外到装好”的顺序列出。

**SR 微动**（最终本体 X 19.0–25.5、Y 56.05–68.85、Z 13.7–19.5）：

(−16.25, 1.55, −14.75, 90) → (−16.25, 1.55, −10.5, 90) → (−16.25, 1.8, −10.5, 90) → 原地转到 yaw 0 → (−16.25, 1.8, +0.5, 0) → (−16.25, 0, +0.5, 0) → (−0.5, 0, +0.5, 0) → 落座

**SF 微动**（最终本体 X 18.5–25.0、Y 41.85–54.65、Z 13.7–19.5）：

(−15.75, 15.75, −14.75, 90) → (−15.75, 15.75, −10.5, 90) → (−15.75, 16.0, −10.5, 90) → 转到 yaw 0 → (−15.75, 16.0, +0.25, 0) → (−15.75, 13.0) → (−12.5, 13.0) → (−12.5, 12.75) → (−12.25, 12.75) → (−12.25, 9.5) → (−8.75, 9.5) → (−8.75, 9.25) → (−8.5, 9.25) → (−8.5, 3.0) → (−6.75, 3.0) → 转到 yaw 90 → (−6.75, 2.0) → (−5.25, 2.0) → (−5.25, 1.75) → (−5.0, 1.75) → (−5.0, −0.5) → (−3.25, −0.5) → 转回 yaw 0 → (−3.25, −0.5, +0.5) → (−3.25, 0, +0.5) → (−0.5, 0, +0.5) → 落座

中间各点 Z 均为 +0.25。

**SR 挡板：**

(−12.15, 2.2, −14.75, 0) → (−12.15, 2.2, +0.3, 0) → (−12.15, 0, +0.3, 0) → (−4.5, 0, +0.3, 0) → (−0.3, 0, +0.3, 0) → 落座

**SF 挡板：**

(−11.85, 15.8, −14.75, 90) → (−11.85, 15.8, −10.5, 90) → (−11.85, 16.05, −10.5, 90) → 转到 yaw 0 → (−11.85, 16.05, +0.3, 0) → (−11.85, 13.0) → (−10.3, 13.0) → (−10.3, 9.5) → (−6.5, 9.5) → (−6.5, 2.0) → (−4.5, 2.0) → (−4.5, 0) → (−0.3, 0, +0.3) → 落座

**执行方要做的：**
- 用最终 BODY 和最终零件，以同样的方法重跑这些路线：脚本是 `cad/l2_r4_author/guided_paths.py`，路线数据 `guided_routes.json`，零件数据 `loose_parts.json`；
- 再对每条路线的转折点做**精确** BRep 距离复核；
- 如果最终 BODY 有偏差导致碰撞，在碰撞点附近局部调整路线点，并记录调整内容。

### 4.3 键帽、钢销、螺钉

- **键帽：改为沿 −X 直线推入（r4 设计修改 D7，见 §4.4 和附录 A.6）。** 原来那条“先插卡舌”的路线已被作者证明不可行（§4.4），所以取消远端卡舌，把外向限位改到铰链处。
- **钢销：** 从顶面窗口竖直压入。执行方在 L2-r3 已用 Ø2 探针验证可达，r4 要用最终 BODY 复验。
- **挡板螺钉：** 竖直从底部拧入，位置 (17.9, 43.0) 和 (17.9, 70.4)。螺丝刀轴线（Ø4 圆柱，从 Z 0 到 12.1）不得碰到 BODY。

### 4.4 键帽路线的精确复核（作者）

**作者的精确 BRep 复核（`cad/l2_r4_author/key_paths_exact.py`）：** 用 L2-r3 发布的键帽和 V2 BODY，检查“先插卡舌”路线：绕卡舌附近的竖直轴把铰链端向外摆出 15°，沿 Y 滑出 1.5，再沿 +X 移出。

**结论：不可行。**

| | 转 2° | 转 3° | 转 15° | 滑出和移出阶段 |
|---|---:|---:|---:|---:|
| SF 相交体积 mm³ | 0.0007 | 0.037 | 2.04 | 仍有 0.01–0.16 |
| SR 相交体积 mm³ | 0.0019 | 0.049 | 2.02 | 0.08–0.44 |

**原因：**
- 卡舌在 Y 向伸到端圈后面 0.5 mm（SF 卡舌末端 Y 57.1，端圈从 Y 56.6 开始），可开口在 Y 向只有 ±0.3 mm 余量，平移解不开；
- 铰链端紧贴开口边，铰节（Ø2.65，中心 Y 45）的前缘 Y 43.675 已经在开口起点 Y 43.9 之外；
- 绕卡舌转出时，连接筋会扫进隔墙端圈。

**r4 修改 D7（执行方实现并验证）：**
1. **取消**远端外向限位卡舌和连接筋（SF、SR 都取消）。
2. **铰轴向开口内移 0.3 mm：** SF 铰轴 (29.0, **45.3**)，SR 铰轴 (29.0, **69.7**)。BODY 上的上下铰耳和钢销孔随之移动。
3. **铰节改为 Ø2.5**（钢销孔 Ø1.05 不变，孔壁 0.725）。这样铰节前缘为 SF Y 44.05、SR 后缘 Y 70.95，都在开口之内（余量 0.15），键帽可以沿 −X 直线穿过开口。
4. **铰链止动耳（新的外向限位）：**
   - 键帽铰节顶端加一个径向止动耳：Z 19.85–20.75，宽 0.8，从铰轴伸到半径 2.3，静止时朝 +X；
   - BODY 上铰耳开一条朝 +X 敞开的装入槽：宽 1.0（Y = 铰轴 Y ± 0.5），从铰轴到上铰耳外端，止动耳沿 −X 滑进去；
   - 再在槽里铣出一个扇形让位：从静止的 0° 到按压方向 +8°（SF 为绕 +Z 的正角，SR 为负角）；
   - 向外转动时，止动耳碰到槽的另一侧壁停住，止挡角 ≤ 0.5°；
   - 静止时由微动按钮的零间隙轻微预压，把止动耳压在止挡面上，不会晃动。
5. **推杆压盘从 Ø3.0 改为 Ø2.6**（球冠半径和高度按比例缩小）。原来的 Ø3.0 下缘在 Z 15.1，低于开口下沿 Z 15.2，直推时会擦到。改小后，止挡时 0.40 mm 的滑移内压盘仍然压在按钮上（按钮 Ø2.0）。
6. **动作参数重算：** 力臂变为 SF 4.95、SR 5.25。推杆处行程 0.60 不变，所以止挡角约为 SF 6.96°、SR 6.56°。执行方按实际铰轴做刚体旋转重算，再更新 §6 的 G5 和 S3 / S4，以及止挡柱、止挡筋的位置。

**装入路线（D7 之后）：**
- 键帽从壳外沿 −X 直线推入，直到铰节到达铰轴、止动耳进入槽内；
- 钢销从顶面窗口压入；
- 然后装入微动并做零间隙调整，预压使止动耳靠上止挡。

**执行方验证：**
- 对 −X 直推的每个姿态（每 0.25 mm），用**精确 BRep** 算键帽与 BODY 的相交体积，必须 ≤ 0.001 mm³；
- 0 到止挡的按压扫掠也要重做（G5）；
- 体素法在 0.3 mm 配合处会出现假碰撞（作者遇到过），不能作为结论。
- 改完后，检查开口、铰耳、扇形槽在 BODY 外表面都不可见（不破皮）。
