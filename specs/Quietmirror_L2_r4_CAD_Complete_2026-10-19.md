## 2. 装配顺序（G6）

1. 两颗 D2F-01F 先焊好导线。
2. 微动从 BODY 底部开口进入，在内侧空间（X 5–17、Z 13.7–19.5）摆正，沿 +X 推入并入 BODY 的开关槽（坐在底板上）。
3. SF_RETAINER、SR_RETAINER 同样从底部进入，沿 +X 贴到开关后面，导线和端子穿过槽口；从底部拧 2 颗 M2 × 5。
4. 键帽从外侧装入（先插卡舌），钢销从顶面窗口压入。
5. 滚轮载架、电子件等按 R3.2 原顺序装配。

**G6 验收：**
- 对每个零件（2 颗微动、2 块挡板、2 只键帽、2 根钢销、4 颗螺钉及螺丝刀轴线），用最终 BODY 做刚体路径检查：平移，加上必要的绕 Z 轴转动（每 5° 一个姿态）。每个姿态都不得穿模，间隙 ≥ 0.25。
- 写出路径点表和截图。
- 已装入的零件要当作后续零件的障碍物。
- 作者的体素宽度优先搜索脚本见附录 C，可以直接复用。注意：作者这次搜索到发文时还没跑完（状态空间很大），**本文没有给出已验证的路径**。执行方必须自己跑出路径；建议先人工给出候选路径点，再逐姿态检查，比全空间搜索快得多。

## 3. G2 / G3 判据（写入 INTERFERENCE_REPORT）

| 类别 | 判据 |
|---|---|
| 固定件 ↔ 电子实体件 | 间隙 ≥ 0.5 |
| 活动件 ↔ 任何件（FDM） | ≥ 0.3（扫掠） |
| **功能配合**（单独列表） | 铰链钢销 Ø1.0 / 孔 Ø1.05；滚轮载架转轴端面游隙 0.20–0.35；侧键止挡筋 ↔ 止挡柱在止挡角时接触；卡舌静止时贴端圈；开关坐底板。这些属于有意接触，非螺纹实体相交 ≤ 0.001 mm³ |
| **预留区**（BATTERY_SERVICE、OPTICAL_PATH） | 不得被**其他元件**侵入；BODY 塑料与预留区相交 ≤ 0.001 mm³ 即可，不要求 0.5 间隙 |
| **天线禁区** | 区内不得有导电件（PCB 铜层、金属螺钉、电池、钢销）；塑料 BODY 不受限 |
| **走线**（*_ROUTE_EST） | 不穿模，与实体间隙 ≥ 0.2 |
| 电池本体 | ≥ 0.5（r3 实测 0.6） |

## 5. G8 整壳刚度（作者已算）

**算法：** 方案 §1.2 的选面、约束和网格设置（附录 B）。R3.2 的两个侧键挡墙工况在 L2 中不存在，不参加比较，侧键受力路径改由 S7 检查。

**几何：** 发布的 `BODY.step` 加上 D1、D4、D5、D6，即附录 A 的 V2。

| 工况 | R3.2 2.4 / 2.0 / 1.6 | L2-r3 发布版 2.4 | **r4（V2）2.4 / 2.0 / 1.6** | r4 最低比值 |
|---|---|---:|---|---:|
| palm_down_20N | 105.64 / 105.97 / 105.04 | 106.18（100.5%） | 143.35 / 144.45 / 142.41 | **136%** |
| left_main_root（+X） | 24.95 / 24.63 / 24.47 | 22.26（89.2%） | 31.70 / 31.28 / 31.54 | **127%** |
| right_main_root（−X） | 24.28 / 23.97 / 23.93 | 22.84（94.1%） | 27.98 / 27.59 / 27.53 | **115%** |
| LC3_squeeze_2x2N | 496.43 / 502.0 / 497.99 | 376.55（75.9%） | 922.03 / 923.32 / 931.07 | **184%** |
| press_A_d16 | 62.21 / 62.15 / 61.77 | 62.92（101.1%） | 74.24 / 74.70 / 73.86 | **119%** |
| press_B_d16 | 56.21 / 53.9 / 55.31 | 54.76（97.4%） | 60.53 / 57.72 / 59.10 | **106.9%** |

- 三档网格全部完成，18 个求解的力和力矩平衡都通过。1.6 mm 档峰值内存 4.99 GB。
- **执行方机器只有约 16 GB：**
  - 关掉其他程序，可用内存 ≥ 10 GB 时再跑；
  - 逐个工况串行，每个工况结束就释放求解器；
  - 求解器用 CalculiX 默认的 SPOOLES 直接法（作者用它跑通了三档）。不要用作者没测过的 iterative 设置。
  - 不得因为内存不够而降档或少跑工况。
- **试算过但没采用的方案：**
  - 只恢复 Y54 外臂：几乎没有作用；
  - 只把后斜撑恢复为圆杆：+0.3%；
  - 托架并入但不加竖撑：主键根只有 95%；
  - 加竖撑但不加粗 Y67.5：指压 B 只有 99.5%。
- **执行方重算 G8 时必须用自己建好的最终 BODY**，和本表偏差 > 3% 时，说明原因。
