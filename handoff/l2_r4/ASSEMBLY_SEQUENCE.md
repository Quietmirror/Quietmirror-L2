# L2-r4 装配顺序与可达性

单位为 mm；+X 为拇指侧，−Y 为前端，+Z 向上。脚贴粘贴面 Z=5.2，估计脚贴厚度0.8，鼠标垫平面 Z=4.4。

1. 核对打印件与实物开关，清理支撑、孔和端子槽；先给两颗侧键开关焊接COM/NO线。
2. 依次装入SR开关、SF开关、SR挡板、SF挡板。SF开关会经过SR挡板位置，顺序不能互换。
3. 从底部拧入带参考垫圈的两颗M2×5自攻螺钉，固定挡板。
4. 按实测尺寸调整推杆PET膜，将两键帽沿−X直推到位，再从顶窗插入竖直钢销。
5. 装配主键、滚轮载架组和H电子件；电池与插头按下方已验证的可拆模块顺序操作。
6. 接通电路后才进行通断、手感、回弹、无线和充电测试；这些没有被CAD仿真代替。

## 电池与插头

电池路线通过：True；插头工具接近通过：True。

1. Disconnect the estimated battery connector using the checked front2mm tool profile
2. Remove main keys and removable wheel carrier assembly
3. Remove screwed H electronic modules and free flexible wires and actual battery retention
4. Follow the saved rigid extraction path toward the bottom; retain the integral BODY and both side modules
5. Reverse the route to insert the battery, then restore wiring, retention and removable modules

实际姿态、最小距离和保留障碍物见 [battery_service_path.json](../../reports/l2_r4/battery_service_path.json)。不能从静态放入结论推断装拆可行，也不能在实物中弯折电池来绕过框架。
