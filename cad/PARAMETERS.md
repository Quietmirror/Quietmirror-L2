# 参数说明

所有长度单位为 mm，角度如有另行声明。`parameters.json` 是建模输入；`build_mouse.py` 负责构造和导出。STEP 可在其他 CAD 中编辑，但原始参数与构造逻辑保存在 Python / JSON 中。

## 坐标

导出模型采用右手 XYZ：**X 正侧为无名指/小指，X 负侧为拇指；Y 正方向朝鼠标前端；Z 朝上。** 前端 Y=0，后端 Y=-90，脚贴安装面 Z=0。

为便于测量，JSON 内 `y` 数值采用“从前端向后量”的正距离，例如滚轮 `y=15.5` 导出后为 Y=-15.5。脚贴和包络报告使用已经转换后的真实 CAD 坐标。

## 主要输入

| 参数 | V0.1 | 含义与影响 |
|---|---:|---|
| `length` | 90 | 后脚平台最末端位置，以及底框/后部站位；不缩放指肚接触面 |
| `max_width` | 62 | 前部保护筋与右托边的外宽目标；必须大于接触面与凸台实际范围 |
| `height` | 31 | 左主键/滚轮的高度基准；不改变壁厚或整手比例 |
| `grip_width` | 54 | 两侧接触区中心外表面的名义夹持宽度；曲面边缘会更宽 |
| `left_key`, `right_key` | 各 24.4 × 40 | 独立的 x、y、宽、长、相对高度、曲率半径 |
| 主键 `height_offset` | 左 0，右 -1.2 | 顶点高度 = `height + height_offset` |
| 主键 `curvature_radius` | 95 | 浅凸球面半径；数值更大则更平 |
| `thumb_contact` | 长42，高19，中心13.6 | 拇指浅凹的位置、长度、高度及曲率（R95） |
| `right_contact` | 长46，高19，中心12.6 | 无名指/小指接触区，曲率 R110 |
| `side_buttons` | y=33/47，z=21.5 | 两个固定凸台的前后、高度和长10.5；中心距14 |
| `wheel` | y=15.5，Ø15，宽5.2 | x/y、直径、宽度、相对高度均可改；默认顶点31 |
| `sensor` | x=0，y=48，孔14×18 | 参考定位框的开口与位置；没有装配孔或光学高度保证 |
| `wall` | 1.8 | 主键及侧面主要接触字段的法向壁厚 |
| `contact_rim_thickness` | 2.4 | 接触区外围加厚带，为圆角保留材料 |
| `contact_edge_radius` | 1.0 | 主接触边圆角；不能任意大于薄壳可容纳的半径 |
| `rib_diameter` | 2.8 | 主要三维承力筋直径 |
| `base_rib_width/height` | 2.6 / 2.6 | 底部连接筋 |
| `inner_anchor_pad_depth/span` | 3.2 / 5.6 | 筋端埋入的内侧小承力垫，接合区局部总厚约3.9 |
| `foot_diameter/thickness` | 8.8 / 2.4 | 脚贴平台直径/厚度，安装面始终 Z=0 |

`human_data` 保存约 230 mm 手长和约 190 mm 张开跨度，**不会进入几何缩放计算**。掌宽、指节长、实际握姿保持 null。

## 改参数的边界

本模型支持分部位修改，并非任意组合都自动可行的优化器。缩短、减窄或大幅移动接触区可能使筋脱离或形成干涉；`build_mouse.py` 与 `validate_mouse.py` 会检查输出。不得通过删掉断开的部件来隐藏失败。

已另外验证一组邻近参数：长94、外宽64、高32、握宽56，左右主键中心后移1、滚轮后移1.5、两个侧键后移1，CAD仍为有效单一实体，外接尺寸64×94×32。该项仅证明参数驱动在这一组合下可用；未打印该变体，也不代表完整参数范围已验证。见 `reports/parameter_smoke_check.json`。

固定按键支柱、固定轮轴、内侧承力垫都是 V0.1 的试握结构。装配版应另建版本，删除固定占位、重新设计转轴/弹性机构/开关受力路径；不应仅删除几个实体后宣称可装配。
