# V0.2 参数、坐标与可编辑范围

源文件 `build_v02.py`，参数 `parameters_v02.json`。辅助几何函数和电子包络定义调用 `build_mouse.py`，两个Python文件都应保留。

全部单位mm。导出X正向是无名指/小指侧、负向是拇指侧；Y正向朝前，前端Y=0、尾端Y=-90；Z向上。JSON里的y为“距前端向后”的正距离，建模时取负号。五个脚贴粘贴基面Z=0，脚贴材料不含在模型中。

| 参数 | 当前值 | 作用与限制 |
|---|---|---|
| length | 90 | 结构站位与尾脚长度；接触点y独立，不随手长缩放 |
| max_width | 62 | 最大外宽目标；STEP实测61.989、STL约61.984，差异来自曲面和三角化 |
| height | 31 | 滚轮顶最高点；壳顶约30，调整高度也改变壳体曲线Z |
| grip_width | 54 | 腰部调节目标；当前d=46、Z=13时截面宽54.043 |
| wall | 1.8 | 外壳向内法向偏移厚度，不是简单的X/Z缩小 |
| shell_floor_z | 1.0 | 壳体下边缘高于五脚基面的距离 |
| shell_stations | 10组d/w/h | 90 mm基准下的距前端、半宽、顶部高度；人为设计控制量，不是人体实测 |
| left_key / right_key | x/y/width/length | 两个主键接触区独立位置和大小，通过窄缝轮廓体现、宽桥连接固定 |
| key_outline_width | 0.65 | 窄缝宽，非按键行程；未切断的桥宽5 mm |
| wheel | x/y/height_offset/diameter/width/opening | 当前Ø15×5.2，距前端17；顶Z=31，开口8.4×18.2 |
| side_buttons | y/z/length | 当前距前端33/47，Z20.6，长10.5；X随夹持目标联动 |
| foot_diameter / foot_thickness | 8.8 / 2.4 | 五个共面平台，粘贴Ø7–7.5圆点脚贴，顶边R0.35 |
| base_rib_width / base_rib_height | 2.6 / 2.6 | 连续底框；下缘高于脚贴基面 |
| rib_diameter | 2.8 | 斜筋；滚轮支撑也为2.8 |
| sensor | x/y/frame_z/开口宽长 | 定位区14×18，距前端48；不是真实光学孔或装配孔 |

曲面采用超椭圆截面 `x^4/w^4 + z^4/h^4 = 1` 的样条放样，使顶部平展、侧面连续下降。腰部和后段独立控制。当前XZ截面主体左右相近；右手属性主要来自左侧键、右托边和不对称五脚，不宣传为已验证的倾斜人体工学壳。

侧键凸台R1.2、固定滚轮边缘R1.0、右托边R1.2，主键轮廓平面转角R4.5。前端壳边和窄缝出口没有统一做成R1–2，打印后轻修毛刺；若实物指肚触到缝边，下一轮移动轮廓或加局部圆角。

改参数后运行构建、验证、渲染、重新切片。一次邻近参数检查见 `reports/v02/parameter_smoke_check.json`，不保证任意极端参数都能布尔合并。断开、壁厚明显降低或五脚不共面应先修复再打印。

STEP包含实体几何；JSON+Python才是参数化源。`--params`只改变输入路径，目前输出仍写入`exports/v02/`；保留其他版时先复制输出或更改脚本输出目录。
