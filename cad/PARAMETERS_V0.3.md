# V0.3 参数、坐标与侧键接口

入口：[build_v03.py](build_v03.py)，数据：[parameters_v03.json](parameters_v03.json)。单位mm；导出X向右、Y向前、Z向上；鼻部Y=0，尾端Y=-90，脚贴粘贴基面Z=0。JSON里滚轮、按键的正数`y`表示距前端的距离，生成时取负数。

| 参数 | 默认值 / 意义 |
|---|---|
| length / max_width / height | 90 /62 /31；外形试握基准，不能由手长等比推导 |
| grip_width | 54；中段宽度控制目标，实际截面还受壳高和曲面影响，应以验证报告为准 |
| shell_stations | 距前端位置、半宽、高度的独立设计控制点；不是人体测量 |
| side_profile_power | 4；横向超椭圆指数。中段更平主要通过纵向宽度控制实现 |
| wall | 1.8目标壁厚；内腔用带纵向斜率补偿的截面放样，并留0.08 mm计算余量，实际法向厚度需重新检查 |
| rear_cavity_end | 81；最后一小段低尾根加实，避免内腔与底筋相切形成薄片 |
| left_key / right_key | 各自X、距前端Y、宽、长；默认23 ×41，中心X±14.2、Y24 |

| side_buttons | 两个键的Y、Z、长度；默认Y33/47、Z19.2、长10.8 |
| side_interface | 窗口、键面、导向段和内限位边尺寸；仅为打印配合原型 |
| ventilation | 孔宽9、构造长度9、内角R0.9；三排距前端54/66/78，4+4+2孔 |

## 侧键配合原型

默认壳孔在YZ平面尺寸12.0 ×6.6，角半径1.7；键面为10.8 ×5.4、接触边R1.1。因此名义单边间隙0.6 mm，适合首轮FDM配合观察，不能当成已经校准的生产公差。内侧导向加强台裁到壳体内部，外表面不会额外鼓出。

键帽有一个8.6 ×3.8的导向段和13.2 ×6.2 ×1.6的内侧限位边。限位边沿前后方向比窗口长，不能从外侧硬塞过窗口。安装时经开放底部送入壳内，再向外推入窗口。名义轴向间隙0.3 mm，使用内侧可移除胶带暂时防止键帽向内脱落；不要为装入而硬压壳壁。

`side_button_assembly_V0.3.step`保存实际装配坐标。单件`side_button_*_PRINT`文件已把内侧限位边朝热床旋转并移到Z0，不能直接以该打印坐标判断安装位置。两个键帽默认同形，分别导出是为了后续单独修改。

FIT文件把同样的两个键帽各用两处1.2 ×1.6 ×4的内侧短连接固定到壳体，使整件保持一个连通实体。SHELL文件去掉键帽和这四处临时连接，保留窗口与导向台。

没有设计活铰链、弹簧、开关柱塞、真实预压或行程。0.3 mm是静态接口空隙，**不代表真实按键行程**。侧键板尺寸确认后再修改限位边、受力柱、支座和回弹结构。

## 修改与复现

在项目根运行`python cad/build_v03.py`，生成到`exports/v03/`。`--params`可指定另一个JSON，输出目录仍是V0.3，请先备份想保留的版本。之后运行`validate_v03.py`、`render_v03.py`和切片步骤。

长度调整会带动底框和曲面站位；主键、滚轮、侧键和孔排位置是显式控制值，不会被自动“人体比例化”。大幅改变参数后，孔与触面、筋、按键的避让需要重新设计。脚贴中心、左右侧支撑和轮架也有默认90 mm版的设计常数，参数化不代表任意参数组合都能得到合格实体。
